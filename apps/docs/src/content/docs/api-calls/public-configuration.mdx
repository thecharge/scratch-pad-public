## Goal

The configuration is public: it needs no token, and it works even when authentication is switched off. These are recorded examples. Changing measurements and progress counters use labelled placeholders. Stream read boundaries are combined; progress shows representative first and last samples. Repeated working-task polls are shown once per task. Complete recordings and checks remain in internal evidence.

Category: API calls. This page has 4 step(s). 4 passed.

## Before you start

- The api address is `https://localhost:8443`.
- The mcp address is `https://localhost:8443/mcp`.
- A bearer access token with the scopes read, write, admin. The commands show `<YOUR_ACCESS_TOKEN>` where your token goes.

Expected outcome: an error

Actual outcome: an error

Command:

```bash
curl --request PATCH 'https://localhost:8443/v1/config' \
  --header 'authorization: Bearer <YOUR_ACCESS_TOKEN>' \
  --header 'accept: application/json' \
  --header 'content-type: application/json' \
  --data '{"bannerText":"Hello"}'
```

Response (error, HTTP 401):

```json
{
  "error": {
    "code": 401,
    "details": [
      {
        "@type": "type.googleapis.com/google.rpc.ErrorInfo",
        "domain": "docs.example.test",
        "reason": "AUTH_NOT_ENABLED"
      }
    ],
    "message": "Authentication is not enabled on this server.",
    "status": "UNAUTHENTICATED"
  }
}
```

Challenge header:

```text
Bearer resource_metadata="http://localhost/.well-known/oauth-protected-resource"
```
