## Goal

Create a book, read it, change one field, archive it, delete it softly and bring it back. These are recorded examples. Changing measurements and progress counters use labelled placeholders. Stream read boundaries are combined; progress shows representative first and last samples. Repeated working-task polls are shown once per task. Complete recordings and checks remain in internal evidence.

Category: API calls. This page has 14 step(s). 14 passed.

## Before you start

- The api address is `https://localhost:8443`.
- The mcp address is `https://localhost:8443/mcp`.
- A bearer access token with the scopes read, write. The commands show `<YOUR_ACCESS_TOKEN>` where your token goes.
