## Goal

A caller follows a reindex while it runs. Over HTTP the caller reads a stream of events. Over MCP the caller subscribes to the operation, reads its state as a resource and watches it for a short time. These are recorded examples. Changing measurements and progress counters use labelled placeholders. Stream read boundaries are combined; progress shows representative first and last samples. Repeated working-task polls are shown once per task. Complete recordings and checks remain in internal evidence.

Category: API calls. This page has 8 step(s). 8 passed.

## Before you start

- The api address is `https://localhost:8443`.
- The mcp address is `https://localhost:8443/mcp`.
- A bearer access token with the scopes read, write, admin. The commands show `<YOUR_ACCESS_TOKEN>` where your token goes.
