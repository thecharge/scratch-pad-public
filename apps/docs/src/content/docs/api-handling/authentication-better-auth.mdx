## Before you start

- The api address is `https://localhost:8443`.
- The mcp address is `https://localhost:8443/mcp`.
- A bearer access token with the scopes read. The commands show `<YOUR_ACCESS_TOKEN>` where your token goes.

## Steps

### HTTP: Call without a token

Flag: **PASSED**

Where: GET /v1/publishers/acme/books

Action: Call books.list to List the books of a publisher. Token scopes: no token.

Expected result: The call fails with the reason TOKEN_MISSING.

Checks:

- PASSED: Outcome is an error
- PASSED: The error reason is TOKEN_MISSING
- PASSED: The HTTP status is 401
- PASSED: The WWW-Authenticate header names the protected-resource metadata `http://localhost/.well-known/oauth-protected-resource`

Expected outcome: an error

Actual outcome: an error

Command:

```bash
curl --request GET 'https://localhost:8443/v1/publishers/acme/books' \
  --header 'content-type: application/json' \
  --header 'accept: application/json'
```

Response (error, HTTP 401):

```json
{
  "error": {
    "code": 401,
    "details": [
      {
        "@type": "type.googleapis.com/google.rpc.ErrorInfo",
        "domain": "docs.example.test",
        "reason": "TOKEN_MISSING"
      }
    ],
    "message": "A bearer token is required.",
    "status": "UNAUTHENTICATED"
  }
}
```

Challenge header:

```text
Bearer resource_metadata="http://localhost/.well-known/oauth-protected-resource"
```
