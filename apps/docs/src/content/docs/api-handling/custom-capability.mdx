## Goal

A capability you define is served as an HTTP route, an MCP tool and an OpenAPI operation from one definition. A tool-only item is an MCP tool with no HTTP route. A skill in a skill package is read through the skill tools. Each one is a normal MCP tool or skill. So it passes the same MCP conformance checks as the built-in ones. The tool is listed. It has an input schema and an output schema. A bad call gives an error result. Policy decides who sees it. These are recorded examples. Changing measurements and progress counters use labelled placeholders. Stream read boundaries are combined; progress shows representative first and last samples. Repeated working-task polls are shown once per task. Complete recordings and checks remain in internal evidence.

Category: API handling. This page has 6 step(s). 6 passed.

## Before you start

- The api address is `https://localhost:8443`.
- The mcp address is `https://localhost:8443/mcp`.
