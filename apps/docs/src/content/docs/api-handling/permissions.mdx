## Before you start

- The api address is `https://localhost:8443`.
- The mcp address is `https://localhost:8443/mcp`.
- A bearer access token with the scopes read. The commands show `<YOUR_ACCESS_TOKEN>` where your token goes.

## Steps

### HTTP: A reader cannot create a book

Flag: **PASSED**

Where: POST /v1/publishers/acme/books?bookId=dune

Action: Call books.create to Create a book. Token scopes: read.

Expected result: The call fails.

Checks:

- PASSED: Outcome is an error

Expected outcome: an error

Actual outcome: an error

Command:

```bash
curl --request POST 'https://localhost:8443/v1/publishers/acme/books?bookId=dune' \
  --header 'authorization: Bearer <YOUR_ACCESS_TOKEN>' \
  --header 'accept: application/json' \
  --header 'content-type: application/json' \
  --data '{"title":"Dune","author":"Frank Herbert","authorEmail":"frank@example.com"}'
```

Response (error, HTTP 403):

```json
{
  "error": {
    "code": 403,
    "details": [
      {
        "@type": "type.googleapis.com/google.rpc.ErrorInfo",
        "domain": "docs.example.test",
        "reason": "POLICY_DENIED"
      }
    ],
    "message": "You are not allowed to call books.create.",
    "status": "PERMISSION_DENIED"
  }
}
```

### HTTP: Without a token a required call is refused

Flag: **PASSED**

Where: GET /v1/publishers/acme/books

Action: Call books.list to List the books of a publisher. Token scopes: no token.

Expected result: The call fails.

Checks:

- PASSED: Outcome is an error

Expected outcome: an error

Actual outcome: an error

Command:

```bash
curl --request GET 'https://localhost:8443/v1/publishers/acme/books' \
  --header 'content-type: application/json' \
  --header 'accept: application/json'
```

Response (error, HTTP 401):

```json
{
  "error": {
    "code": 401,
    "details": [
      {
        "@type": "type.googleapis.com/google.rpc.ErrorInfo",
        "domain": "docs.example.test",
        "reason": "TOKEN_MISSING"
      }
    ],
    "message": "A bearer token is required.",
    "status": "UNAUTHENTICATED"
  }
}
```

Challenge header:

```text
Bearer resource_metadata="http://localhost/.well-known/oauth-protected-resource"
```
