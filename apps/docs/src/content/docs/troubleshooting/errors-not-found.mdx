## Goal

A name that points to nothing, or a name written wrongly, gives a clear error. These are recorded examples. Changing measurements and progress counters use labelled placeholders. Stream read boundaries are combined; progress shows representative first and last samples. Repeated working-task polls are shown once per task. Complete recordings and checks remain in internal evidence.

Category: Troubleshooting. This page has 8 step(s). 8 passed.

## Before you start

- The api address is `https://localhost:8443`.
- The mcp address is `https://localhost:8443/mcp`.
- A bearer access token with the scopes read, write, admin. The commands show `<YOUR_ACCESS_TOKEN>` where your token goes.
